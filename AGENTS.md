## 3. Technical Specifications for the Agent

### A. Build System (`Makefile`)
The Makefile must use `pspsdk`. Typical structure:
```make
TARGET = redriver2_psp
OBJS = src/platform/psp_main.o src/platform/psp_video.o src/platform/psp_input.o src/platform/psp_audio.o \
       # (plus all Game/, PsyCross/, and utils/ object files)

CFLAGS = -O3 -G0 -Wall -DPSP -DNG_PSP $(INCDIR)
CXXFLAGS = $(CFLAGS) -std=c++11 -fno-exceptions -fno-rtti
ASFLAGS = $(CFLAGS)

LIBDIR =
LIBS = -lpspgu -lpspgum -lpspaudio -lm -lc -lstdc++

EXTRA_TARGETS = EBOOT.PBP
PSP_EBOOT_TITLE = Redriver2 PSP
PSP_EBOOT_ICON0 = sce_sys/ICON0.PNG
PSP_EBOOT_PIC0 = sce_sys/PIC0.PNG

PSPSDK=$(shell psp-config --pspsdk-path)
include $(PSPSDK)/lib/build.mak
```

### B. Platform Layer Requirements (`src/platform/`)
1. **`psp_main.cpp`**:
   - Initialize PSP screen, controller, audio, and file system.
   - Set up callback threads for exit (`pspDebugScreenInit`, `SetupCallbacks`).
   - Call game main loop (`main_game_loop()` or equivalent from `redriver2`).
2. **`psp_video.cpp`**:
   - Initialize `sceGuInit()`, `sceGuStart()`, buffers (`VRAM`), projection and view matrices via `sceGum`.
   - Implement PsyCross hook functions for framebuffer clearing, primitive rendering, and frame swapping (`sceGuSwapBuffers()`).
3. **`psp_input.cpp`**:
   - Poll controller using `sceCtrlReadBufferPositive(&pad)`.
   - Map PSP d-pad, analog stick, and face buttons to Driver 2 key/gamepad states.
4. **`psp_audio.cpp`**:
   - Initialize `pspaudio` / `pspaudiolib` channels.
   - Feed PCM audio buffers generated by the game audio engine.
5. **`utils/fs.cpp`**:
   - Ensure file paths point correctly to `ms0:/PSP/GAME/Redriver2PSP/data/` or relative path `data/`.
